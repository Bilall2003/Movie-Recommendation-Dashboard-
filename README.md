# ✨ Features

## 📊 Exploratory Data Analysis (EDA)

✔ Upload your own CSV movie dataset

✔ Dataset overview

✔ Data types inspection

✔ Missing values analysis

✔ Duplicate detection

✔ Descriptive statistics

✔ Data health report

✔ Interactive visualizations

✔ Clean, responsive Streamlit interface

---

## 🎥 Movie Recommendation Engine

### 🔍 Normal Search

Recommend movies based on:

- Genre
- Similar movie characteristics

### 🤖 Hybrid Search

Uses Machine Learning with:

- Genre filtering
- K-Means Clustering
- Similarity-based recommendations

### ⚙ Customization

- Choose **1–5 recommendations**
- Fast and interactive predictions

# 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/movie-magic.git

# Navigate to project
cd movie-magic

# Install dependencies
pip install -r requirements.txt

# Run Streamlit app
streamlit run app.py
```
